# Setting Up the Klaviyo API

### 📝 Introduction 
   This guide provides step-by-step instructions for setting up and using the Klaviyo API to access customer data and manage marketing campaigns, lists, and profiles programmatically.

### 📡 Prerequisites 

   To get started with the Klaviyo API, create an account if you haven't already signed up for a Klaviyo account. You can follow along with this [video](https://www.youtube.com/watch?v=0AnKXEcgcGQ).

> **Note**: If you are given access to an existing account then you can skip the above step and move to the next section.

### 🔑 Generating an API Key

   To interact with the Klaviyo API, you need to generate an API token. Follow these steps:

   1. **Go to the Klaviyo Dashboard**: After confirming your account, you will be directed to the Klaviyo dashboard. This is the main interface where you can manage your account and access various features.

   2. **Access API Settings**: On the leftmost end of the dashboard, click on the icon that represents your business name. This action will prompt a menu to appear. From the menu, select Settings. In the Settings section, navigate to API keys section. Here, you will find the option to create and manage your private API keys.

   3. **Select API Key Scope**: After clicking on Private API Key, a section will open where you need to choose the scope of the API key. There are three available scopes, and you can select the one that best fits your needs based on the functionalities you intend to use.

   4. **Create the API Key**: Once you have chosen the access scopes, enter a name for your private API key and click on Create. This will generate the API key required for querying the Klaviyo API, enabling you to integrate and interact with the platform effectively.
